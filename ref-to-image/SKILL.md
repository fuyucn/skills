# 参考图生图·提示词框架

> 保留的是这个人，改变的是这个场景。

---

## 核心工作模式

| 模式 | 输入 | 输出 |
|------|------|------|
| **单人换装/换场景** | 1张参考图 + 场景描述 | 同一人物，新场景/新造型 |
| **双人合照** | P1照片 + P2照片 + 场景描述 | 两人同框新图 |
| **多人场景** | P1~PN照片 + 场景描述 | 多人同框新图 |
| **风格迁移** | 1张参考图 + 风格描述 | 同一人物，新艺术风格 |

**上传顺序约定**：第1张=P1，第2张=P2，第N张=PN，最后粘贴提示词文本。

## 提示词结构

### 通用原则

- 每个参考人物使用独立编号：`[P1]`、`[P2]`
- 每个人物先写**身份锚点**，再写**可变内容**
- **可以改变**：服装、发型、表情、姿态、场景、光线、构图、艺术风格
- **必须保留**：脸型轮廓、五官比例、眉眼关系、鼻梁与鼻头、唇形、下颌线、人种特征、肤色类型、面部骨相、年龄感
- **谨慎改变**：大幅改变发型时需加强五官约束；夜景/侧脸/远景会降低相似度

### 反美化偏差约束（关键·适用任何人种参考图）

GPT Image 2 有明显的「默认美化」倾向——即使参考图清晰，生成时也会朝流行审美方向漂移。**通用反偏差写法**（不预设参考图人种）：

```
不要美化、不要西化、不要东方化、不要混血化。
不要把眼睛画得更大，不要加重双眼皮。
不要把鼻梁画得更高、鼻头更挺。
不要把下巴画得更尖、脸型更小。
不要把肤色画得更白或更均匀。
不要朝任何流行美学（网红脸 / 欧美脸 / 混血脸 / V 脸）方向修改。
保留参考图人物原本的真实辨识度，即使不符合主流审美也必须保持原貌。
```

⚠️ **不要写「不要欧美化」**——这预设了参考图是亚洲人。如果参考图本身是欧美人，这反而会强行东方化。用上面的通用写法。

### 单人模板

```
请根据第1张参考图生成新图，人物为 [P1]。

[身份锚点]
[P1] 必须 100% 像第1张参考图的同一位成年人：
保持脸型轮廓、五官位置与比例、眉形与眉眼距离、眼睛形状（含内/双眼皮、
眼距、眼尾走向）、鼻梁与鼻头、唇形与厚薄、下颌线、人种特征、
肤色类型、面部骨相、年龄感和整体气质。
允许改变服装、发型、表情、姿态、场景和画面风格，但不要生成陌生人脸。

[反美化偏差]
不要美化、不要西化、不要东方化、不要混血化。
不要把眼睛画得更大，不要加重双眼皮，不要把鼻梁画得更高，
不要把下巴画得更尖，不要把肤色画得更白。
不要朝网红脸 / 欧美脸 / 混血脸 / V 脸方向修改。
保留参考图人物原本的真实辨识度，即使不符合主流审美也必须保持原貌。

[可变内容]
场景：[场景描述]
服装：[新服装描述]
发型：[保留原发型 / 新发型描述]
表情：[新表情描述]

[画面要求]

不要 AI 假脸，不要过度磨皮。
```

## 安全审查友好写法

| 高风险表达 | 推荐替代表达 |
|-----------|-------------|
| 性感、诱惑、撩人 | 优雅、时尚、高级、自然自信 |
| 暧昧挑逗 | 浪漫氛围、温柔互动、自然亲近 |
| 接吻、嘴唇相触 | 近距离对视、额头轻靠、牵手、自然靠近 |
| 火辣身材 | 健康体态、修身剪裁、时尚造型 |
| 暴露、透视 | 简洁剪裁、轻盈材质、优雅礼服 |

**亲密场景**：默认改写为「浪漫、自然、优雅、非挑逗的近距离互动」。
**年龄不明确或偏年轻**：不生成亲密/性感场景，先确认均为成年人。

## Gotchas

- **风格描述覆盖人物身份**：使用强烈艺术风格（如「复古胶片」「插画风」）时，五官会被风格同化。需在风格后明确加：「风格只作用于光线、色彩和背景，不改变人物五官、脸型和身份特征」。
- **多人参考图中只有一位清晰主体**：如果参考图中有两人，模型无法确定 P1 指的是哪一位。每人提供单独参考图。
- **大幅改变发型导致不像本人**：发型是重要身份锚点之一。大改发型时必须加强五官约束（眉眼关系、下颌线、鼻子）。
- **夜景/侧脸/远景大幅降低相似度**：正脸+自然光参考图效果最好；侧脸+暗光时即使提示词正确，相似度仍明显下降。
- **不要默认安全降级**：涉及性感/亲密/暴露场景时，先尝试推到边界（Thinking 模式 + 专业风格锚定），不要主动改写为「克制版」。被拒再回退。详细策略 → `ref-image-compliance-prompt-master/SKILL.md` 的「表达力扩展库」。
- **负向约束反向触发审查**：「不要色情、不要裸露」这种串本身是触发词列表，会拉高拒绝率。底部约束极简化，只保留「成年人 + 身份锚定 + 不要 AI 假脸」三项。

## 回答工作流（Agentic Protocol）

### Step 1：识别输入

| 用户输入 | 处理方式 |
|---------|----------|
| 1张参考图 + 换场景/换装 | 单人模板 |
| 2张参考图 + 合照需求 | 双人合照模板 |
| 3+张参考图 | 读取 references/templates.md 多人模板 |
| 提到 P1/P2 | 按上传顺序建立人物对应 |
| 只说"生成合照"但没说场景 | 给3个安全场景选项，或默认「自然电影感合照」 |
| 涉及亲密互动 | 改写为「浪漫、自然、优雅、非挑逗的近距离互动」 |
| 年龄不明确或偏年轻 | 不生成亲密/性感场景，先确认均为成年人 |

### Step 2：构建提示词

1. 每个人物独立段落，`[P1]` `[P2]` 标注
2. 每人先写身份锚点，再写可变内容
3. 场景/光线/构图/风格单独成段
4. 多人图必须加防混淆约束
5. 末尾加人物一致性 + 安全约束块

### Step 3：自检

- [ ] 上传顺序与P1/P2对应关系是否明确？
- [ ] 每个人物是否都有独立身份锚点？
- [ ] 多人图是否写明站位、服装、面部朝向？
- [ ] 是否加入防止面孔/服装互换的约束？
- [ ] 是否避免裸露、性暗示、低龄化、强迫感？

## 诚实边界

- 实际效果取决于平台对参考图的权重处理（GPT Image 2 / Seedance / 即梦等各不同）
- 多人场景时，人物越多，单个人物的容貌精准度越难保证
- 参考图质量直接决定生成上限，低清/遮挡/侧脸图会显著降低一致性
- 本Skill不用于生成未成年人的换装、亲密、性感化场景
