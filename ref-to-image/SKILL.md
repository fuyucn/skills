# 参考图生图·提示词框架

> 保留的是这个人，改变的是这个场景。

---

## 核心工作模式

| 模式 | 输入 | 输出 |
|------|------|------|
| **单人换装/换场景** | 1张参考图 + 场景描述 | 同一人物，新场景/新造型 |
| **双人合照** | P1照片 + P2照片 + 场景描述 | 两人同框新图 |
| **多人场景** | P1~PN照片 + 场景描述 | 多人同框新图 |
| **风格迁移** | 1张参考图 + 风格描述 | 同一人物，新艺术风格 |

**上传顺序约定**：第1张=P1，第2张=P2，第N张=PN，最后粘贴提示词文本。

## 提示词结构模板

### 通用原则

- 每个参考人物使用独立编号：`[P1]`、`[P2]`、`[P3]`
- 每个人物先写**身份锚点**，再写**可变内容**
- **可以改变**：服装、发型、表情、姿态、场景、光线、构图、艺术风格
- **必须保留**：脸型轮廓、五官比例、眉眼关系、鼻梁与鼻头、唇形、下颌线、肤色类型、年龄感、整体气质
- **谨慎改变**：大幅改变发型时需加强五官约束；夜景/侧脸/远景会降低相似度
- 肤色可受光线影响，但不得改变肤色类型或人种特征

## 容貌保留关键参数

| 特征 | 推荐描述方式 | 注意事项 |
|------|------------|----------|
| 脸型轮廓 | 圆脸/鹅蛋脸/方圆脸/长脸/下颌线清晰 | 最重要的身份锚点之一 |
| 眉眼关系 | 眉眼距离、眉形、眼距、眼睛走向 | 比单独写"大眼睛"更稳定 |
| 眼睛 | 单眼皮/内双/双眼皮/杏眼/丹凤眼/眼尾上扬 | 避免把眼睛统一放大 |
| 鼻子 | 鼻梁高度、鼻头形状、鼻翼宽窄 | 不要默认高鼻梁化 |
| 嘴唇 | 唇形、厚薄、嘴角走向 | 避免网红唇 |
| 面部比例 | 三庭五眼、脸长宽比例 | 多人防混淆时最重要 |
| 肤色类型 | 冷白/暖白/自然肤色/小麦色/健康肤色 | 可受光线影响，但不改变肤色类型 |
| 年龄感 | 成年、成熟感、青年成人、中年成人 | 不生成未成年人或低龄化形象 |
| 发型 | 可保留或改变，大改时要加强五官约束 | 大改发型会降低相似度 |
| 气质 | 温柔/知性/清冷/活泼/干练/文艺 | 辅助一致性，不能替代五官描述 |

## 安全审查友好写法

| 高风险表达 | 推荐替代表达 |
|-----------|-------------|
| 性感、诱惑、撩人 | 优雅、时尚、高级、自然自信 |
| 暧昧挑逗 | 浪漫氛围、温柔互动、自然亲近 |
| 接吻、嘴唇相触 | 近距离对视、额头轻靠、肩并肩、牵手、自然靠近 |
| 火辣身材 | 健康体态、修身剪裁、时尚造型 |
| 暴露、透视 | 简洁剪裁、轻盈材质、优雅礼服 |
| 欲望感 | 电影感、情绪张力、温柔叙事 |

**亲密场景处理规则**：
- 默认改写亲密互动为「浪漫、自然、优雅、非挑逗的近距离互动」
- 年龄不明确或偏年轻时，不生成亲密、性感、暧昧或强身体接触场景
- 审查严格时，删除身体接触细节，只保留「浪漫氛围、双人中近景、温柔互动」

## 失败修复提示词

### 不像参考人物

```
加强一致性：请更严格保留参考图人物的脸型轮廓、五官比例、眉眼关系、
鼻子形状、唇形、下颌线、肤色类型和年龄感。
不要美化成另一张脸，不要网红化，不要欧美化，不要改变面部比例。
```

### P1/P2面孔混淆

```
修复混淆：[P1]只能使用第1张参考图的人脸特征，[P2]只能使用第2张参考图的人脸特征。
不要交换两人的脸、发型、服装、站位或身体，不要融合两个人的五官。
```

### 脸部变形或不清晰

```
修复清晰度：所有人物脸部必须完整、清晰、无遮挡、无变形，
避免背脸、强侧脸、过暗光线、过远构图和面部挤压。
```

### 过度美颜或AI感

```
降低AI感：保留真实皮肤纹理、自然毛孔和真实面部细节。
不要塑料皮肤，不要过度磨皮，不要夸张大眼、高鼻梁、尖下巴或统一网红审美。
```

### 审查不过

```
安全降级：删除裸露、性感、挑逗、床、强身体接触等高风险描述，
改为自然合照、优雅造型、浪漫氛围、温柔对视、电影感光线和高级摄影构图。
```

### 风格覆盖了人物身份

```
降低风格强度：风格只作用于光线、色彩、服装、背景和画面质感，
不改变人物五官、脸型、年龄感和身份特征。
```

## 参考图质量检查

### 推荐参考图
- 正脸或轻微侧脸，脸部清晰无遮挡
- 分辨率较高，五官可辨认
- 单人参考图中只有一个清晰主体
- 多人任务中每人各自提供单独参考图

### 低质量参考图风险

| 参考图问题 | 可能结果 | 建议 |
|-----------|----------|------|
| 墨镜/口罩/刘海遮眼 | 五官无法稳定保留 | 补充无遮挡正脸图 |
| 强侧脸或背脸 | 正脸生成不像本人 | 补充正脸或三分之二侧脸图 |
| 低清/模糊/过暗 | 脸部漂移、AI感增强 | 换高清图 |
| 参考图中多人同框 | 主体识别错误 | 明确指出P1是哪位，最好裁剪单人 |
| 夸张滤镜或重度美颜 | 生成结果像滤镜脸 | 提供自然光真实照片 |
| 年龄不明确或偏低龄 | 安全风险升高 | 不生成亲密、性感或暧昧场景 |

## 回答工作流（Agentic Protocol）

**核心原则：先判断人物数量和目标场景；信息不足先追问；涉及亲密/年龄不明确时默认安全降级。**

### Step 1：识别输入

| 用户输入 | 处理方式 |
|---------|----------|
| 1张参考图 + 换场景/换装 | 单人模板 |
| 2张参考图 + 合照需求 | 双人合照模板 |
| 3+张参考图 | 多人模板 |
| 提到 P1/P2 | 按上传顺序建立人物对应 |
| 只说"生成合照"但没说场景 | 给3个安全场景选项，或默认「自然电影感合照」 |
| 只说"保持长相"但没说改变什么 | 追问：换场景/换装/换风格/生成合照？ |
| 涉及亲密互动 | 改写为「浪漫、自然、优雅、非挑逗的近距离互动」 |
| 年龄不明确或偏年轻 | 不生成亲密/性感场景，先确认均为成年人 |
| 风格迁移需求 | 使用单人模板，风格描述替换场景描述 |

### Step 2：必要追问

- 人物数量不明：确认有几位参考人物及上传顺序
- 目标场景不明：说明想换到什么场景，或选「室内/街景/旅行/棚拍/电影感」
- 风格不明：确认「真实摄影/杂志大片/电影感/插画/动漫/商业广告」
- 互动关系不明：多人图确认站位、距离和互动方式
- 安全边界不明：涉及亲密时确认所有人物均为成年人，改写为平台友好表达

### Step 3：构建提示词

1. 每个人物独立段落，`[P1]` `[P2]` 标注
2. 每人先写身份锚点，再写可变内容
3. 场景/光线/构图/风格单独成段
4. 多人图必须加防混淆约束
5. 末尾加人物一致性 + 安全约束块

### Step 4：输出格式

默认输出一版可直接复制的中文提示词。按平台调整：
- **GPT Image 2**：自然语言，明确P1/P2对应，优先正向要求
- **Seedance/即梦**：分段式结构，增加镜头语言、动作连续性、角色一致性
- **Midjourney**：可附加英文关键词和构图风格词

### Step 5：自检

- [ ] 上传顺序与P1/P2对应关系是否明确？
- [ ] 每个人物是否都有独立身份锚点？
- [ ] 可变内容是否与身份锚点分离？
- [ ] 多人图是否写明站位、服装、面部朝向？
- [ ] 是否加入防止面孔/服装/发型/站位互换的约束？
- [ ] 是否避免裸露、性暗示、低龄化、强迫感？
- [ ] 所有人物是否默认为成年人？
- [ ] 是否给出真实感与不过度美颜约束？
- [ ] 多图生成是否追加人物一致性约束块？

## 诚实边界

- 实际效果取决于平台对参考图的权重处理（GPT Image 2 / Seedance / 即梦等各不同）
- 多人场景时，人物越多，单个人物的容貌精准度越难保证
- 面部特征过于相似的两人（如双胞胎）可能导致混淆，需额外特征区分描述
- 参考图质量直接决定生成上限，低清/遮挡/侧脸图会显著降低一致性
- 本Skill不用于生成未成年人的换装、亲密、性感化或身份仿真场景；如参考人物年龄不明确，默认使用非亲密、非性感、普通肖像或合照场景
