# 参考图生图·提示词框架

> 保留的是这个人，改变的是这个场景。

---

## 核心工作模式

| 模式 | 输入 | 输出 |
|------|------|------|
| **单人换装/换场景** | 1张参考图 + 场景描述 | 同一人物，新场景/新造型 |
| **双人合照** | P1照片 + P2照片 + 场景描述 | 两人同框新图 |
| **多人场景** | P1~PN照片 + 场景描述 | 多人同框新图 |
| **风格迁移** | 1张参考图 + 风格描述 | 同一人物，新艺术风格 |

**上传顺序约定**：第1张=P1，第2张=P2，第N张=PN，最后粘贴提示词文本。

---

## 提示词结构

### 通用原则

- 每个参考人物使用独立编号：`[P1]`、`[P2]`、`[PN]`
- 每个人物先写**身份锚点**，再写**可变内容**
- 人物参考图默认是 **identity source（身份来源）**，不是普通风格参考或灵感参考
- 必须明确生成“参考图中的同一位真实人物”，不是“相似人物”
- **可以改变**：服装、表情、姿态、场景、光线、构图、艺术风格
- **默认保留**：发型、发际线、头颅轮廓、脸型轮廓、五官比例、眉眼关系、鼻梁与鼻头、唇形、下颌线、颧骨结构、肤色类型、面部骨相、年龄感、自然轻微不对称
- **如用户明确要求改变发型**：只改变发型样式，不改变发际线、额头比例、头颅轮廓、脸型和五官
- **谨慎改变**：大幅改变发型、强风格化、夜景、侧脸、远景、遮挡都会降低相似度；此时必须加强身份锚点和脸部清晰度约束
- **脸部可见性**：除非用户明确要求远景、背影或遮挡，人物脸部应清晰可见、无遮挡、不过度侧脸，并在画面中占足够比例
- **年龄处理**：普通换场景/换装任务应保持参考图年龄感；只有涉及亲密、性感、暧昧、暴露、情侣互动等敏感场景时，才加入“确认均为成年人”的安全约束

### 多参考图隔离原则

- 人物参考图只用于身份锚定
- 姿势参考图只用于姿态和动作
- 风格参考图只用于色彩、质感、光影、构图语言和艺术风格
- 服装参考图只用于服装款式、材质和搭配
- 场景参考图只用于环境、背景、空间和氛围
- 不要把不同参考图中的脸型、五官、肤色、发型、人种特征或年龄感互相混合
- 多人图中，`[P1]` 的身份只能来自第1张人物参考图，`[P2]` 的身份只能来自第2张人物参考图

## 反美化偏差约束

GPT Image 2 有明显的「默认美化」倾向。即使参考图清晰，生成时也可能朝流行审美、模板脸、过度对称脸方向漂移。

### 通用反偏差写法

以下写法适用于任何人种参考图，不预设参考图人物的人种或地域特征。

```
[反模板脸]
不要生成：AI 网红脸 / 模板化流行审美脸 / 偶像脸 / 娃娃脸 /
动漫脸 / 幼态脸 / 过度对称脸 / 塑料皮肤 / 奇幻模板脸。

[反美化操作]
不要美化、不要西化、不要东方化、不要混血化。
不要把眼睛画得更大，不要加重双眼皮。
不要把鼻梁画得更高，不要把鼻头画得更挺。
不要把下巴画得更尖，不要把脸型画得更小。
不要把肤色画得更白、更均匀或更光滑。
不要朝任何模板化流行审美方向修改。
不要过度对称，真实人脸应保留自然轻微不对称。

[正向真实感锚定]
保留参考图人物原本的真实辨识度，即使不符合主流审美也必须保持原貌。
保留 subtle natural asymmetry（自然轻微不对称）。
保留 authentic eyes（真实眼睛形状）、realistic nose（真实鼻子）、
realistic lips（真实嘴唇）、realistic skin texture（真实皮肤纹理）、
natural human expressions（自然的人类表情）。

[强可识别性声明]
[P1] 必须明显可识别为第1张参考图中的同一位真实人物。
[P2] 必须明显可识别为第2张参考图中的同一位真实人物。
```

注意：

- 不要写「不要欧美化」或「保留亚洲面孔」，这会预设参考图人种
- 用「不要朝任何模板化流行审美方向修改」替代带方向性的审美词
- 「自然轻微不对称」是反 AI 化的关键；AI 默认会把五官做得过度对称

## 安全审查友好写法

| 高风险表达 | 推荐替代表达 |
|-----------|-------------|
| 性感、诱惑、撩人 | 优雅、时尚、高级、自然自信 |
| 暧昧挑逗 | 浪漫氛围、温柔互动、自然亲近 |
| 接吻、嘴唇相触 | 近距离对视、额头轻靠、牵手、自然靠近 |
| 火辣身材 | 健康体态、修身剪裁、时尚造型 |
| 暴露、透视 | 简洁剪裁、轻盈材质、优雅礼服 |

**亲密场景**：默认改写为「浪漫、自然、优雅、非挑逗的近距离互动」。

**年龄不明确或偏年轻**：不生成亲密/性感/暧昧/暴露场景，先确认均为成年人。

**普通换场景/换装**：不主动加入“成年人”约束，避免改变人物年龄感；只要求保持参考图年龄感。

## Gotchas

- **风格描述覆盖人物身份**：使用强烈艺术风格（如「复古胶片」「插画风」「动漫风」「3D」）时，五官会被风格同化。需在风格后明确加：「风格只作用于光线、色彩、材质、背景和画面语言，不改变人物五官、脸型和身份特征」。
- **多人参考图中只有一位清晰主体**：如果参考图中有两人，模型无法确定 P1 指的是哪一位。每人应提供单独参考图。
- **大幅改变发型导致不像本人**：发型是重要身份锚点之一。大改发型时必须加强五官约束，并保护发际线、额头比例、头颅轮廓、脸型、眉眼关系、下颌线和鼻子。
- **夜景/侧脸/远景大幅降低相似度**：正脸+自然光参考图效果最好；侧脸+暗光时即使提示词正确，相似度仍明显下降。需要增加“脸部清晰可见、无遮挡、不过度侧脸、不过远”。
- **多参考图容易混脸**：必须明确身份、姿势、服装、背景、风格各自来自哪张图。人物身份不能跨参考图混合。
- **不要默认安全降级**：涉及亲密/性感/暴露场景时，优先改写为安全审查友好的高级、自然、非挑逗表达；被拒后再进一步收敛。详细策略 → `ref-image-compliance-prompt-master/SKILL.md` 的「表达力扩展库」。
- **负向约束反向触发审查**：「不要色情、不要裸露」这种串本身可能触发审查。底部约束极简化，只保留「身份锚定 + 不要 AI 假脸 + 必要时确认成年人」。

## 回答工作流（Agentic Protocol）

### Step 1：识别输入

| 用户输入 | 处理方式 |
|---------|----------|
| 1张参考图 + 换场景/换装 | 单人模板 |
| 2张参考图 + 合照需求 | 双人合照模板 |
| 3+张参考图 | 读取 `references/templates.md` 多人模板 |
| 提到 P1/P2 | 按上传顺序建立人物对应 |
| 只说"生成合照"但没说场景 | 给3个安全场景选项，或默认「自然电影感合照」 |
| 涉及亲密互动 | 改写为「浪漫、自然、优雅、非挑逗的近距离互动」 |
| 年龄不明确或偏年轻 | 不生成亲密/性感/暧昧/暴露场景，先确认均为成年人 |
| 提到风格迁移/转绘/动漫/插画/3D | 使用风格迁移模板，并加强“风格不改变脸” |

### Step 2：构建提示词

1. 每个人物独立段落，使用 `[P1]` `[P2]` `[PN]` 标注
2. 每人先写身份锚点，再写可变内容
3. 明确写“同一位真实人物”，不要只写“像”或“相似”
4. 场景、光线、构图、风格单独成段
5. 多人图必须加防混淆约束
6. 人物参考图只用于身份锚定；风格、姿势、服装、背景参考必须与身份参考分离
7. 默认加入脸部清晰度约束：脸部清晰可见、无遮挡、不过度侧脸、不过远
8. 如果改变发型，必须保护发际线、额头比例、头颅轮廓、脸型和五官
9. 末尾加人物一致性 + 安全约束块

### Step 3：自检

- [ ] 上传顺序与 P1/P2 对应关系是否明确？
- [ ] 每个人物是否都有独立身份锚点？
- [ ] 是否明确写了“同一位真实人物”，而不是只写“像”？
- [ ] 是否保护脸型、五官比例、眉眼关系、鼻子、嘴唇、下颌线、肤色类型、年龄感？
- [ ] 是否避免把“成年人”写进普通身份锚点导致年龄漂移？
- [ ] 如果改变发型，是否保护了发际线、额头比例、头颅轮廓、脸型和五官？
- [ ] 是否避免使用会预设人种方向的偏差词？
- [ ] 人脸是否要求清晰可见、无遮挡、不过远、不过度侧脸？
- [ ] 多人图是否写明站位、服装、面部朝向？
- [ ] 多人图是否加入防止面孔、服装、站位互换的约束？
- [ ] 多参考图时，身份参考和风格/姿势/服装/背景参考是否隔离？
- [ ] 是否避免裸露、性暗示、低龄化、强迫感？

## 失败修复方向

当生成结果“不像本人”时，优先增强以下内容：

```
问题：生成结果像陌生人 / 只是相似但不是本人

修复：
请重新生成。最高优先级是身份一致性。
[P1] 必须是第1张参考图中的同一位真实人物，不是相似人物。
请降低风格化、美化、滤镜和模板脸倾向。
保留脸型轮廓、五官比例、眉眼关系、鼻梁与鼻头、唇形、下颌线、
颧骨结构、肤色类型、年龄感、发际线、头颅轮廓和自然轻微不对称。
脸部必须清晰可见、无遮挡、不过度侧脸、不过远。
```

当生成结果“过度美化”时：

```
问题：生成结果变成网红脸 / 偶像脸 / AI 假脸

修复：
不要美化，不要模板化，不要过度对称。
不要把眼睛画大，不要把鼻梁画高，不要把下巴画尖，不要把肤色画白或磨皮。
保留参考图人物真实皮肤纹理、自然轻微不对称和原本的真实辨识度。
```

当多人图“混脸/换脸/站位混乱”时：

```
问题：P1/P2 身份混淆

修复：
[P1] 的身份只能来自第1张参考图。
[P2] 的身份只能来自第2张参考图。
不要互换面孔、发型、服装、肤色、站位或表情。
不要生成融合脸。
每个人脸部都要清晰可见，并保持各自参考图中的真实辨识度。
```

## 诚实边界

- 实际效果取决于平台对参考图的权重处理（GPT Image 2 / Seedance / 即梦等各不同）
- 多人场景时，人物越多，单个人物的容貌精准度越难保证
- 参考图质量直接决定生成上限，低清、遮挡、侧脸、暗光、远景图会显著降低一致性
- 强风格化会天然降低脸部精确度，需要额外加强身份锚点
- 本 Skill 不用于生成未成年人的换装、亲密、性感化场景
