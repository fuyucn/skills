# 扩展模板

> 读取条件：需要多人模板（3人以上）或完整示例时。

## 多人模板（3人以上）

```
请根据上传顺序生成一张[N]人同框图。
第1张=[P1]，第2张=[P2]，第3张=[P3]，以此类推。

[P1] 身份锚点：
保持脸型轮廓、五官比例、眉眼关系、鼻子、唇形、肤色类型、年龄感和整体气质。
服装：[P1服装] | 发型：[P1发型] | 位置：[P1位置] | 面部朝向：[正脸/轻微侧脸]

[P2] 身份锚点：
保持脸型轮廓、五官比例、眉眼关系、鼻子、唇形、肤色类型、年龄感和整体气质。
服装：[P2服装] | 发型：[P2发型] | 位置：[P2位置] | 面部朝向：[正脸/轻微侧脸]

[P3] 身份锚点：
保持脸型轮廓、五官比例、眉眼关系、鼻子、唇形、肤色类型、年龄感和整体气质。
服装：[P3服装] | 发型：[P3发型] | 位置：[P3位置] | 面部朝向：[正脸/轻微侧脸]

场景：[场景描述] | 互动：[人物互动方式]
构图：尽量让每个人脸部清晰可见，避免过远、遮挡或背脸。
风格：[摄影/电影感/写实] | 光线：[光线描述]

多人一致性约束：
每个人必须清楚对应自己的参考图。
不要交换任何人的脸、服装、发型、站位或身体。
不要让人物脸部过小、模糊、遮挡或彼此相似化。
所有人物均为成年人，画面自然优雅，非挑逗，不要裸露。
```

---

## 容貌保留关键参数

| 特征 | 推荐描述方式 | 注意事项 |
|------|------------|----------|
| 脸型轮廓 | 圆脸/鹅蛋脸/方圆脸/长脸/下颌线清晰 | 最重要的身份锚点之一 |
| 眉眼关系 | 眉眼距离、眉形、眼距、眼睛走向 | 比单独写"大眼睛"更稳定 |
| 眼睛 | 单眼皮/内双/双眼皮/杏眼/丹凤眼 | 避免把眼睛统一放大 |
| 鼻子 | 鼻梁高度、鼻头形状、鼻翼宽窄 | 不要默认高鼻梁化 |
| 嘴唇 | 唇形、厚薄、嘴角走向 | 避免网红唇 |
| 肤色类型 | 冷白/暖白/自然肤色/小麦色 | 可受光线影响，但不改变肤色类型 |
| 年龄感 | 成年、成熟感、青年成人、中年成人 | 不生成未成年人或低龄化形象 |

## 常用场景示例

### 双人街头合照

```
请根据参考图生成一张电影感街头合照。
第1张参考图=[P1]，第2张参考图=[P2]。

[P1] 身份锚点：保持第1张参考图人物的可识别身份特征。
服装：米白色简约针织上衣，高腰裤 | 表情：温柔微笑，眼神自然 | 位置：画面左侧

[P2] 身份锚点：保持第2张参考图人物的可识别身份特征。
服装：简约深色外套 | 表情：温柔微笑，自然放松 | 位置：画面右侧

两人并排站立，距离自然亲近，肩并肩，不刻意摆拍。
场景：城市街头傍晚，暖色灯光，背景虚化，行人模糊。
高端摄影质感，电影感，柔和自然光，浅景深，35mm镜头感。

[P1]和[P2]必须清楚对应各自参考图，不要交换面孔，不要欧美化，不要AI假脸。
```

### 单人换装换场景

```
[P1] 参考图中的人物，保留真实容貌特征完全不变。

新场景：日式居酒屋，暖黄灯光，木质装饰
新服装：日式和风棉麻连衣裙，淡蓝色
新表情：放松微笑，端着清酒杯
姿态：侧坐，自然优雅

高端杂志摄影风格，温暖灯光，浅景深，真实摄影感，
不要变成陌生人，不要过度磨皮，保留真实辨识度。
```
