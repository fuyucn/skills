# 失败修复提示词

> 读取条件：生成结果出现问题时。

## 不像参考人物

```
加强一致性：请更严格保留参考图人物的脸型轮廓、五官比例、眉眼关系、
鼻子形状、唇形、下颌线、肤色类型和年龄感。
不要美化成另一张脸，不要网红化，不要欧美化，不要改变面部比例。
```

## P1/P2面孔混淆

```
修复混淆：[P1]只能使用第1张参考图的人脸特征，[P2]只能使用第2张参考图的人脸特征。
不要交换两人的脸、发型、服装、站位或身体，不要融合两个人的五官。
```

## 脸部变形或不清晰

```
修复清晰度：所有人物脸部必须完整、清晰、无遮挡、无变形，
避免背脸、强侧脸、过暗光线、过远构图和面部挤压。
```

## 过度美颜或AI感

```
降低AI感：保留真实皮肤纹理、自然毛孔和真实面部细节。
不要塑料皮肤，不要过度磨皮，不要夸张大眼、高鼻梁、尖下巴或统一网红审美。
```

## 审查不过

```
安全降级：删除裸露、性感、挑逗、床、强身体接触等高风险描述，
改为自然合照、优雅造型、浪漫氛围、温柔对视、电影感光线和高级摄影构图。
```

## 风格覆盖了人物身份

```
降低风格强度：风格只作用于光线、色彩、服装、背景和画面质感，
不改变人物五官、脸型、年龄感和身份特征。
```

---

## 参考图质量检查

### 推荐参考图
- 正脸或轻微侧脸，脸部清晰无遮挡
- 分辨率较高，五官可辨认
- 单人参考图中只有一个清晰主体

### 低质量参考图风险

| 参考图问题 | 可能结果 | 建议 |
|-----------|----------|------|
| 墨镜/口罩/刘海遮眼 | 五官无法稳定保留 | 补充无遮挡正脸图 |
| 强侧脸或背脸 | 正脸生成不像本人 | 补充正脸或三分之二侧脸图 |
| 低清/模糊/过暗 | 脸部漂移、AI感增强 | 换高清图 |
| 参考图中多人同框 | 主体识别错误 | 明确指出P1是哪位，最好裁剪单人 |
| 夸张滤镜或重度美颜 | 生成结果像滤镜脸 | 提供自然光真实照片 |
| 年龄不明确或偏低龄 | 安全风险升高 | 不生成亲密、性感或暧昧场景 |
