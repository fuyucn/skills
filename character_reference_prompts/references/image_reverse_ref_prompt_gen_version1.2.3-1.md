# 人物一致性规则

在所有反推提示词中，人物身份一致性必须优先于画面美感。

必须明确写入：

1. 以参考图人物作为唯一身份参考。
2. 生成同一位人物，而不是相似类型的人。
3. 保留参考图人物的脸型、五官比例、眉眼关系、眼距、眼型、鼻型、嘴型、下颌线、下巴、脸颊轮廓、年龄感、神态、气质和整体辨识度。
4. 不要把人物改成通用审美脸、网红脸、模板脸、广告脸或 AI 美女脸。
5. 不要自动美颜，不要瘦脸，不要尖下巴，不要强行大眼，不要垫高鼻梁。
6. 保留真实皮肤质感、自然面部纹理、轻微不对称和细微真实特征。
7. 如果用户要求保留表情，必须强调表情不能改变五官结构。
8. 如果存在俯拍、仰拍、侧脸、头发遮挡、闭眼、微张嘴等因素，必须提醒这些可能降低相似度，并在提示词中加入稳定面部结构的描述。

固定人物一致性表达可使用：

请严格以参考图中的同一位成年人物作为唯一身份参考，生成同一个人，而不是相似类型的人、通用审美脸、网红脸、模板脸或过度精修广告脸。必须保持参考图人物原本的脸型、五官比例、眉眼关系、眼型、眼距、鼻型、嘴型、下颌线、下巴形状、脸颊轮廓、年龄感、神态气质、自然皮肤质感和整体辨识度。服装、背景、姿势、光线和风格可以根据目标画面变化，但人物身份不能变化。

   - 抬头、低头、侧头、轻微歪头。
   - 正面、侧脸、轻微三分之二角度。

   - 眼睛睁开程度。
   - 是否避免眯眼、闭眼、眼神死、斜视。

4. 嘴唇状态：
   - 自然闭合。
   - 轻微放松。
   - 微笑。
   - 轻微张开。
   - 是否露齿。
   - 是否避免夸张嘴型。

5. 手部动作：
   - 双手交握。
   - 手放脸边。
   - 手撑桌面。
   - 手放膝盖。
   - 手扶头发。
   - 手自然垂落。
   - 手指状态。

6. 腿部动作：
   - 双腿并拢。
   - 交叉腿。

   - 一条腿伸出一条腿收拢。
   - 坐姿错落。
   - 站姿重心偏移。

7. 表情强度：
   - 克制自然。
   - 轻微情绪。
   - 不夸张。
   - 不表演式。
   - 不因为表情改变脸部结构。

表情保真固定表达可使用：

面部表情必须保留参考图或目标图中的情绪状态，但不能改变人物身份。眼神、嘴唇、眉眼状态和脸部肌肉变化都应自然克制，不能因为微笑、低头、俯拍、半睁眼、微张嘴或害羞表情而改变眼型、嘴型、脸型、鼻型、下颌线和整体辨识度。

默认建议：

Aspect ratio：优先跟随原图；如果用户未指定，人像写真默认 3:4 或 4:5。

Image type：realistic portrait photography。

Camera：人像优先 50mm / 70mm / 85mm，除非原图明显是广角或手机抓拍。

Framing：根据原图反推近景、半身、全身、高机位、低机位或平视。

Lighting：根据原图反推自然光、柔光、棚拍光、台灯光或电影光。

Style strength：如果重视人物相似度，建议中低到中等。

Identity weight：高。

Pose reference weight：中到偏高，但不要高于 identity weight。

Expression priority：高，尤其用户要求保留表情时。

Skin texture：真实自然皮肤纹理，避免过度磨皮。

Similarity priority：人物身份 > 面部表情 > 动作姿势 > 构图光线 > 风格美感。
