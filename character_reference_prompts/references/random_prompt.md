# random_prompt.md — 超强随机性分行法生图 Skill

## Purpose

根据用户给出的简单方向，自动生成 5-10 张风格不同、构图不同、动作不同、机位不同、表情不同的图片。

用户只会给一个方向，例如：

```
夜晚车内，冷灰梦核，复古ccd
酒店房间，千禧年自拍感
海边夜景，复古dv，柔焦
白色摄影棚，冷灰柔光，朦胧感
街头闪光灯，复古ccd快闪，贴镜摄影
```

你需要自动完成：

1. 理解用户方向
2. 识别是否存在拍摄距离强制指令
3. 从固定稳定库中抽取变量
4. 保证同一批次每张图都明显不一样
5. 按分行法写出每张图的完整提示词
6. 直接调用当前环境可用的生图工具生成图片
7. 默认一次生成 5 张
8. 如果用户指定 n=3、n=8、n=10，则按用户指定数量生成
9. 最多一次生成 10 张
10. 不输出长篇解释，只输出简短说明 + 生图结果
11. 如果当前环境无法直接调用生图工具，则只输出 n 组完整分行法提示词，并提示："当前环境未接入生图工具，只能输出提示词。"

---

# Core Principle

你不能让 AI 自由发挥随机。你必须从下面的稳定库中抽取变量。

每张图至少变化 4 个关键维度：发型、机位、动作、构图、场景、服饰、美瞳、表情、相机。

同一批次中：

- 发型尽量不重复
- 主机位尽量不重复
- 主动作尽量不重复
- 主构图尽量不重复
- 主表情尽量不重复
- 场景细节尽量不重复
- 完整组合不能重复
- 不能生成 5 张看起来只是同一个提示词换几个字的图

如果用户没有指定数量，默认 n=5。如果用户指定超过 10 张，最多只生成 10 张。

---

# Execution Order

每次接到用户方向后，必须按以下顺序执行：

1. 识别用户方向：
   - 场景方向
   - 氛围方向
   - 相机倾向
   - 是否指定数量 n
   - 是否触发拍摄距离控制
2. 选择视觉模板：
   - 自拍流
   - 镜面自拍流
   - 车内POV流
   - 室内酒店流
   - 街头闪光灯流
   - 梦核朦胧流
   - 白棚写真流
   - 海边夜景流
3. 检查是否触发拍摄距离控制：
   - 如果没有触发，按默认随机逻辑执行
   - 如果触发，则整批图片统一遵守对应拍摄距离要求
4. 给每张图分配变量：
   - 相机
   - 发型
   - 美瞳
   - 表情
   - 动作
   - 机位
   - 构图
   - 场景细节
   - 服饰
5. 做冲突检查和重复检查
6. 按分行法生成提示词
7. 调用生图工具生成图片

不要输出内部规划过程。只输出最终分行法提示词或直接生图结果。

# Scene Generation Rules

场景必须根据用户方向生成，不要乱跑。

- 车内：夜晚车内、车窗反光、城市灯光虚化、出租车后座、地下停车场车内
- 酒店：酒店房间、白色床铺、窗边、浴室镜前、冷灰柔光
- 街头：夜晚街道、便利店门口、路灯、霓虹虚化、玻璃反光
- 梦核：极简白色空间、空旷走廊、冷灰薄雾、白色窗边、千禧年记忆感
- 海边：夜晚沙滩、黑沙滩、海面反光、海边栏杆、远处城市灯光
- 白棚：极简白色摄影棚、纯白空间、冷灰柔光、前景虚化遮挡

场景不要写得太长。每张图的场景细节要有区别。

如果触发近景、特写、贴镜摄影，场景仍然要存在，但不要抢人物主体。场景可以作为背景虚化、反光、灯光、前景遮挡、空间氛围来呈现。

# Clothing Generation Rules

服饰要根据场景和氛围生成。要求：简洁、克制、时装感、不要过度暴露、不要低俗。

可用方向：

- 白色宽松长袖上衣
- 浅灰色针织上衣
- 米白色宽松毛衣
- 黑色短外套搭配浅色内搭
- 白色上衣搭配黑色半身裙
- 简洁黑色修身上衣搭配半身裙
- 浅灰色针织上衣搭配白色半身裙
- 米白色连衣裙
- 白色轻薄外套搭配短裙
- 宽松白色睡衣

服饰可以轻微变化，但不要写得太复杂。同一批次服饰尽量不重复。

如果触发特写或贴镜摄影，服饰描述要简洁，不要让服饰抢过脸部和镜头距离。重点仍然是脸部、眼神、表情、发型和镜头压迫感。

# Conflict Check Rules

以下组合禁止：

- 车内第一视角 + 坐在床边
- 车内第一视角 + 对镜自拍
- 镜面自拍视角 + 走路抓拍
- 镜面自拍视角 + 转身抓拍
- 极近距离裁切构图 + 全身留白构图
- 脸部占画面大部分 + 全身留白构图
- 脚后跟机位 + 近景大头构图
- 脚拇指机位视角 + 脸部占画面大部分
- 手机遮脸自拍 + 贴地仰拍
- 白棚写真流 + 车内第一视角
- 海边夜景流 + 坐在床边
- 街头闪光灯流 + 对镜自拍

如果触发拍摄距离控制模式，额外禁止对应模式的禁用项。如果出现冲突，重新抽取其中一个变量。

# Batch Diversity Rules

5 张：发型尽量不重复、主机位尽量不重复、主动作尽量不重复、主构图尽量不重复、主表情尽量不重复、完整组合不能重复。

6-10 张：同一个发型最多 2 次、主机位最多 2 次、主动作最多 2 次、主构图最多 2 次、主表情最多 2 次、美瞳最多 3 次、相机最多 3 次。完整组合绝不重复。

每张图至少变化 4 个关键维度。

# Output Rules

你需要直接生成图片，不要只写提示词。流程：

1. 根据用户方向生成 n 组不同的分行法提示词
2. 把每组提示词分别发送给当前环境可用的图像生成工具
3. 一次性生成 n 张图
4. 输出图片结果

不要写长篇解释，不要询问用户确认，除非用户明确要求先看提示词。

如果用户说"先出提示词"，你才只输出提示词。如果用户说"直接生图"，你必须直接生图。如果用户只给方向，没有说"先出提示词"，默认直接生图。

如果当前环境不能生图，就输出完整分行法提示词，并提示"当前环境未接入生图工具，只能输出提示词。"

每张图必须保留：【相机】里的"闪光灯"、【镜头滤镜】完整段落、【光线氛围】完整段落。

如果用户触发近景、特写、贴镜摄影：整批图片都必须遵守对应模式。不要遗漏。不要合并。不要简写。
