## 本版目标
在保留 v1.1 已经较好的人物相似度和古风氛围基础上，进一步减少模型自动瘦脸、V脸化、削下颌、压窄脸颊、过度精修脸型的问题，使生成结果更接近参考图人物原本的真实脸型、脸宽、面部体积和骨肉关系。

## 最终 Prompt

请以参考图中的人物作为唯一人物身份来源，生成一张新的东方古风人像照片。新图中的人物必须高度保留参考图人物的真实面部身份特征，使观者能够明确判断这是参考图中的同一个人，而不是相似类型的人、AI美女、网红脸或重新设计过的古风角色。

人物身份优先级最高，脸型一致性优先级极高。请严格保持参考图人物原本的脸型宽度、脸颊轮廓、下颌线形状、下巴大小、面部骨相、面部肉感、脸部体积、五官比例和整体头脸比例。不要自动瘦脸，不要把脸变窄，不要把脸颊削薄，不要把下颌变尖，不要把下巴拉长，不要变成V脸，不要为了古风审美而重塑脸型。请保留参考图中真实自然的脸部宽窄比例、颧骨结构、腮部转折、下巴形状和面部饱满度。

请重点保留参考图人物的脸型轮廓、面部骨相、五官比例、眼睛大小与形状、眼距、眉眼关系、鼻梁与鼻头特征、嘴唇厚度与唇形、下巴形状、颧骨结构、发际线、肤色、年龄感、面部气质以及个人辨识度。不要根据通用审美重新美化人物，不要把人物改成更精致、更年轻、更瘦、更尖下巴、更大眼睛、更高鼻梁或更小脸的版本。

新图人物的脸必须看起来像参考图本人在真实拍摄中的自然脸型，而不是经过美颜相机、瘦脸滤镜、AI精修或古风模板化处理后的脸。允许有自然摄影光影带来的轻微明暗变化，但不允许改变脸型结构和头脸比例。宁可保留参考图中真实的脸部宽度、自然脸颊、真实下颌和原始面部比例，也不要生成更符合大众审美但不像本人的精致小脸。

在保持人物身份一致的基础上，将参考图人物塑造成一位身处幽深竹林中的古风女子。人物身穿淡青色古典罗裙，衣料轻盈柔软，裙摆自然垂落并随微风轻轻飘动。罗裙上带有细腻的银线刺绣，在柔和光线下呈现若隐若现的微弱金属光泽。服装整体清雅、克制、古典，不要过度华丽，不要仙侠游戏感。

人物发型可调整为古典发髻，发间点缀白色花卉发饰与垂坠流苏发簪。发型应自然贴合参考图人物原本的头脸比例，不要通过发型制造明显小脸效果，不要用两侧头发遮挡脸颊来显脸小。可以有少量发丝被微风吹动，但必须保证脸部轮廓、脸颊、下颌和五官清晰可见，不能因为发丝、雾气、强光或角度导致人物身份特征丢失。

人物呈半侧身回眸姿态，轻轻看向镜头，表情安静、克制、微微清冷，带有东方古典美人的含蓄气质。但表情必须建立在参考图人物原本的面部气质之上，不要生成陌生的古风模板脸，不要改变人物原本的年龄感、真实表情结构、脸型宽度和面部体积。

场景位于幽深竹林之中，周围有轻柔薄雾弥漫，空气湿润、清冷、安静。竹叶在背景中形成自然层次，远处背景柔和虚化。自然侧逆光从竹叶间透入，在人物肩部、发丝、衣料边缘形成柔和轮廓光，画面带有淡淡的晨雾感和东方诗意。

画面采用真实摄影质感，中景构图，9:16竖向比例，平视视角，90mm人像镜头效果，浅景深，人物面部清晰对焦。构图重点突出人物脸部、上半身、发饰和淡青色罗裙线条，使参考图人物的身份辨识度清楚可见。避免过高俯拍、过度侧脸、过强透视或极端镜头压缩导致脸型变窄、下巴变尖或脸部比例失真。

整体风格融合中国古典美学与现代电影人像摄影。色调以淡青色、灰白色、翠竹绿为主，低饱和、柔和、清冷、高级、自然。画面应具有真实人像摄影质感，而不是二次元插画、游戏角色立绘、AI合成写真或过度修饰的网红古风照。

人物皮肤应保留自然真实的皮肤纹理、细微毛孔、真实面部阴影和原本的面部细节。不要过度磨皮，不要塑料皮肤，不要蜡像感，不要过度美颜，不要通过美颜算法改变脸型、脸宽、下颌和五官比例。宁可保留参考图人物真实的面部特点，也不要为了美化而改变长相。

最终画面应该像是参考图中的同一个人换上淡青色古典罗裙，在竹林薄雾中拍摄的一张电影感古风写真。服装、发型、环境、光影和姿态可以改变，但人物身份、核心长相、真实脸型、脸部宽度、脸颊轮廓、下颌形状、五官比例、年龄感和个人气质必须保持一致。

高清晰度，真实人像摄影质感，面部自然，五官比例稳定，真实脸型稳定，人物身份与参考图高度一致，东方古典美学，竹林薄雾，淡青色罗裙，柔和电影光影，低饱和高级色调，浅景深，细腻服装纹理，自然皮肤质感。

## 参数建议

如果使用图生图、参考图生图或人物一致性模型，建议：

- 参考图权重：高
- 身份一致性强度：高
- Face reference / 人脸参考强度：高
- 重绘幅度：中低或低
- 风格化强度：中低
- 创造性：中低
- 美颜强度：关闭
- 瘦脸 / 美型 / 脸部优化：关闭
- 人脸修复：谨慎使用，避免自动改脸型
- 构图比例：9:16
- 推荐类型：真实摄影、人像摄影、电影感写真
