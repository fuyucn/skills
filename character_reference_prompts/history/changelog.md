# Changelog

## v2.0.7 - 2026-08-15

### 修改内容
- 新增「Expression Freedom / 表情解冻」规则：身份锁定只针对静态面部结构（骨相、五官、脸型、皮肤、年龄感、痣），表情、视线、头部角度由新场景重新生成。
- 删除 `expression consistent with the reference image` 默认写法，改为场景自然表情。
- Main Prompt 增加表情解冻标准句：Same face, new expression。
- Avoid 增加：不复制参考图表情、头部角度、视线；不冻结面部、不僵硬微笑。
- Failure Repair 增加「表情僵硬 / 复制参考图表情」修复句。
- 更新单人/双人 Canonical Template 与 Final Quality Standard。

### 修改原因
2.0.6 身份锁定语言过强，模型在保持人脸一致时把参考图表情一起锁死，导致新图表情僵硬、笑得不自然。

v1.2
- 将原先偏“古风”定向的描述改为通用参考图人像生成模板，适配更多场景。
- 强化“人物身份一致性优先”的原则，明确脸型、五官比例、眉眼关系、年龄感、气质等必须优先保留。
- 统一并补强负向约束，减少自动美颜、网红脸、小脸化、尖下巴、大眼睛、高鼻梁、塑料感、蜡像感等问题。
- 增加对眼镜处理的规则：可去掉眼镜，但必须保留原始眼部特征。
- 明确输出结构，要求模型在信息不足时先提问，而不是直接猜测。
- 删除对特定风格的依赖，让模板可用于古风、现代、写真、插画等通用场景。
- 语言改为更简洁、专业、可直接复制使用的通用提示词风格。
## v1.1 - 2026-06-25

### 修改内容
- 修正 prompt 定义：从“成品图片 prompt”改为“参考图人物肖像生成提示词生成器 prompt”。
- 明确输入结构应包含：
  - 参考图人物信息
  - 任意提示词
- 明确输出目标应是：
  - 可直接用于参考图人物肖像生成新图片的最终 prompt
- 强化“角色定位”为提示词转换器，而不是单纯图片描述器。
- 增加对任意提示词的融合能力说明，使其能适配不同主题、风格、场景。
- 增加更适合图生图工作流的输出结构：
  - 最终 Prompt
  - Negative Prompt
  - 参数建议
- 强化“身份一致性优先”的原则，避免用户任意提示词破坏参考图人物特征。

### 修改原因
之前版本把重点写成了“直接生成古风人像成品 prompt”，没有准确体现你真正需要的能力：  
**把“参考图人物 + 任意提示词”转换成可用于参考图人物肖像生成的 prompt。**

### 预期效果
- 后续只要输入参考图人物信息和任意提示词，就能稳定生成可用的绘图 prompt。
- 更适合做成一个通用的 prompt 生成器。
- 既能保留人物身份，又能适配各种主题和风格。
