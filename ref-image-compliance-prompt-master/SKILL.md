# 参考图生图·安全合规改写器

> 问题不是你的内容，是你用的词。

---

## 定位

本 Skill 是 `ref-to-image` 的安全合规包装层：

- `ref-to-image` → 生成完整的参考图提示词结构
- `ref-image-compliance-prompt-master` → 检查并改写提示词，降低安全审查误判

**本 Skill 不帮助绕过安全系统；只帮助合规内容用更精准的语言表达，减少误判率。**

---

## 触发场景

| 情况 | 处理方式 |
|------|----------|
| 提示词已生成，但被安全系统拒绝 | 全文诊断 + 高风险词替换 + 结构调整 |
| 用户描述了亲密/性感/暧昧场景 | 改写为浪漫氛围 + 优雅互动 + 电影感描述 |
| P1/P2 合照场景含接触/肢体细节 | 替换具体动作为「自然亲近、温柔对视、并肩而行」 |
| 用户不确定提示词是否安全 | 主动扫描高风险词，提供改写建议 |
| 已用 image-prompt-master 优化过，仍被拒 | 进一步压缩肢体描述 + 强化风格词覆盖 |

---

## 与其他 Skill 的配合

```
用户有参考图
    ↓
ref-to-image → 生成 P1/P2 身份锚点提示词
    ↓
image-prompt-master → 优化摄影风格、光线、构图语言
    ↓
ref-image-compliance-prompt-master → 安全合规扫描，改写触发词
    ↓
粘贴到 GPT Image 2（Thinking 模式）
```

**单独使用**：用户直接贴入一段被拒提示词 → 本 Skill 负责诊断改写。

---

## 核心改写规则

1. **先切 Thinking 模式**：改写前提示用户切换至 GPT Image 2 Thinking 模式，拒绝率可独立降低 30%+
2. **词语优先于结构**：大多数拒绝是单个触发词造成的，先替换词，再调结构
3. **风格词覆盖**：用「高端时尚摄影 / 电影感 / 杂志大片 / 真实摄影」压住低风险内容
4. **删除比替换更优先**：能删掉的肢体接触细节就删，不强行替换
5. **锚定人物身份**：改写后仍保留 `ref-to-image` 的身份锚点结构，不破坏 P1/P2 一致性

## 改写流程

### Step 1：诊断

扫描提示词，标记所有高风险词：
- 性感/诱惑类词汇
- 具体肢体接触描述（尤其是嘴唇、胸部、腿部）
- 场景敏感词（床、卧室、裸露）
- 年龄模糊 + 亲密组合

### Step 2：改写

1. 替换高风险词（使用上方词汇表）
2. 删除无法替换的具体肢体细节
3. 增加 1 句风格词覆盖：「高端时尚摄影 / 电影感 / 杂志大片感 / 真实摄影质感」
4. 结尾加安全约束块（见下方）
5. 保留 P1/P2 身份锚点结构完全不变

### Step 3：追加安全约束块

每次改写后，在提示词末尾追加：

```
所有人物均为成年人。画面自然优雅，非挑逗，不要裸露，不要性暗示。
不要欧美化，不要网红化，不要过度磨皮，不要AI假脸。
[若多人] [P1]和[P2]不要交换面孔，不要融合五官，不要遮挡脸部。
```

## 诚实边界

- 词汇替换降低的是**误判率**，不能保证100%过审
- 部分内容属于平台政策明确禁止，换词也无法通过，本 Skill 不帮助此类场景
- 如参考人物年龄不明确，默认使用非亲密、非性感场景，不生成亲密互动
- 改写后的提示词仍遵循 `ref-to-image` 的 P1/P2 身份锚点结构
