# 提示词格式优化器

> 同样的意图，结构变好就能从被拒到通过、从生成不像到生成准确。

---

## 定位

本 skill 专注于**提示词的格式与结构层**：
- 不改变提示词意图（那是 image-prompt-master 和 compliance 的事）
- 只优化结构、节省 token、提升关键约束权重、清除反向触发词

---

## 核心原则

```
原则 1：关键约束必须靠前
        身份锚点 / 风格隔离 / 反偏差 → 前 3 节
        模型有 token 位置偏置，靠前权重大

原则 2：装饰格式 = 浪费
        ═══ 长分隔符 / 大量空行 / emoji 标签 都不帮助模型
        只用 ## 或 [节标题] 简洁标记

原则 3：内容不重复
        同一个约束在 3 个地方重复 = 浪费 token
        要么合并，要么删除冗余

原则 4：负向约束极简
        长串「不要XXX」= 触发词列表，反向激活审查
        只保留绝对必要的 1-3 项

原则 5：每节不超 5 行
        长段落让模型注意力分散
        切成 3-5 行的短节
```

---

## 诊断清单

接到任意提示词后，按此清单扫描：

```
[结构检查]
□ 是否有 ═══ 装饰分隔符？→ 删除
□ 是否有重复约束（同一意思在多处出现）？→ 合并
□ 关键约束（身份/风格隔离/反偏差）是否在前 3 节？→ 不是则前置
□ 节标题格式是否统一？（## 或 [节标题] 选一种）
□ 单节是否超过 5 行？→ 切分

[内容检查]
□ 是否有「不要色情/不要裸露/不要挑逗」长串否定？→ 删除（触发词列表）
□ 是否有自辩句「画面通过 X 表达 Y 而非 Z」？→ 删除（反向暴露意图）
□ 是否有「不要欧美化」类预设人种约束？→ 改通用反偏差
□ 是否缺失「风格隔离声明」？→ 关键约束，必须加
□ 是否缺失「反美化偏差」？→ 关键约束，必须加
□ 五官是否只统一锚定？→ 改分项（眼睛/鼻子/嘴唇独立）

[token 效率]
□ 总字数是否 > 600？→ 考虑压缩
□ 风格描述是否堆叠（5+ 风格词）？→ 选 2-3 个最关键
□ 是否有「装饰性形容词」（绝对/极致/超）→ 删除
```

---

## 标准结构（C 格式）

按以下顺序排列节，每节用 `## 节标题`：

```
1. 模式/版本提醒（GPT Image 2 Thinking 模式 / Grok 视频 等）
2. 参考图绑定（[P1]=第1张参考图 / ONLY facial reference）
3. ## 核心原则（最高优先级声明）
4. ## 身份锚定（必须保留的特征列表）
5. ## 反美化偏差（通用反偏差，不预设人种）
6. ## 反模板脸（8 种禁止类型）
7. ## 风格隔离（声明风格只动光影，不动人脸）
8. ## 主题（一句话）
9. ## 画面内容（具体动作、姿态、场景）
10. ## 构图（比例、布局、视觉焦点）
11. ## 光线（光源、方向、效果）
12. ## 质感（景深、颗粒、色调）
13. ## 防混淆（多人时必加）
14. ## 情绪（关键词列表）
```

不是所有提示词都需要全部 14 节，按需选择。

---

## 节标题写法对比

| 风格 | 例子 | 何时用 |
|------|------|--------|
| **`## 节标题`** | `## 身份锚定` | 多节复杂提示词（推荐默认） |
| **`[节标题]`** | `[身份锚定]` | 紧凑场景，节数 < 6 |
| **`节标题：`** | `身份锚定：` | 极简提示词，节数 < 4 |
| ~~`═══ 节标题 ═══`~~ | 不要用 | 浪费 token，不帮助模型 |

**统一一种风格**，不要混用。

---

## 关键约束位置（强权重区）

GPT Image 2 / Grok 等模型对提示词有 **token 位置偏置**——靠前的内容权重大。

```
[前 30% Token 区域]（最高权重）
- 参考图绑定
- 核心优先级声明  
- 身份锚定
- 反美化偏差
- 风格隔离

[中间 40%]（中等权重）
- 主题
- 画面内容
- 构图
- 光线

[后 30%]（最低权重）
- 质感细节
- 情绪关键词
- 防混淆补充
- 安全约束（极简）
```

**强约束放后面 = 浪费**。如果发现关键约束在尾部，前置。

---

## 反向触发词清理表

| 应该删除 | 原因 | 替换为 |
|---------|------|--------|
| 「不要色情、不要裸露、不要挑逗」串 | 关键词共现激活审查 | 删除即可，或用「成年人 + 风格锚定」 |
| 「画面通过 X 表达 Y 而非 Z」 | 自辩反向暴露意图 | 删除 |
| 「绝非情色、绝非低俗」 | 包含触发词 | 删除 |
| 「不要欧美化」「保留亚洲面孔」 | 预设参考图人种 | 改「不要美化/西化/东方化/混血化」 |
| 「不要儿童/不要未成年」 | 包含触发词 | 改「所有人物均为成年人」 |

## 改写示例

### 输入（典型问题）

```
═══════════════════════════════════════════
【画面要求·必读】
═══════════════════════════════════════════

请使用 GPT Image 2 Thinking 模式生成。
本次生成为艺术创作目的，请用心配合。

═══════════════════════════════════════════
【场景描述】
═══════════════════════════════════════════

清晨卧室，温暖晨光，白色亚麻床品，氛围温柔克制。
两人是成年情侣，[P1] 男性，[P2] 女性。

═══════════════════════════════════════════
【人物表现】
═══════════════════════════════════════════

两人面对面深情对视，眼神温柔，距离适中。
不要裸露，不要性暗示，不要挑逗姿态，不要低俗化。
画面通过眼神和表情传达情感而非身体接触。
不要欧美化，不要变成网红脸。

═══════════════════════════════════════════
【身份】
═══════════════════════════════════════════

[P1] 必须像第1张参考图，[P2] 必须像第2张参考图。
不要 AI 假脸。
```

**诊断**：
- ❌ 5 处 ═══ 装饰分隔符
- ❌ 身份锚定放在最后（应该最前）
- ❌ 长串「不要XXX」（4 项）
- ❌ 自辩句「画面通过眼神而非身体接触」
- ❌ 「不要欧美化」预设人种
- ❌ 总字数膨胀，关键信息密度低

### 输出（C 格式重构）

```
GPT Image 2 Thinking 模式。
[P1]=第1张参考图（男性），[P2]=第2张参考图（女性），均成年人。

## 核心原则
[P1] [P2] 100% 像各自参考图，风格让位于相似度。

## 身份锚定
脸型、五官比例、眉眼形状、内/双眼皮、鼻梁鼻头、唇形、下颌线、
人种特征、肤色、面部骨相、年龄感、发型完全保留。

## 反美化偏差
不要美化/西化/东方化/混血化。
不要画大眼/加双眼皮/抬高鼻梁/缩尖下巴/变白肤色。
不要朝网红脸/V脸方向修改。保留参考图原本辨识度。

## 风格隔离
所有风格关键词只作用于光影和背景，不动人脸。

## 画面
清晨卧室，温暖晨光，白色亚麻床品。
两人面对面深情对视，眼神温柔，距离自然。

## 防混淆
两人不交换面孔/发型，五官不融合，看起来明显是两个人。

所有人物均为成年人。不要 AI 假脸。
```

**改进**：字数从 ~350 → ~250，关键约束前置，删除触发词列表，删除自辩句。

## 工作流（Agentic Protocol）

### Step 1：扫描诊断

按「诊断清单」逐项检查输入提示词，标记所有问题。

### Step 2：分类处理

```
A. 删除项：═══ 分隔符 / 重复约束 / 自辩句 / 装饰词
B. 改写项：「不要 X」串 → 极简化 / 预设人种 → 通用反偏差
C. 重排项：关键约束 → 前置 / 长节 → 切分
D. 补充项：缺失的「身份锚定 / 风格隔离 / 反偏差」补上
```

### Step 3：按 C 格式重构输出

按「标准结构」14 节顺序重排，按需选择需要的节，统一节标题格式。

### Step 4：自检

```
□ 总字数比原版减少了吗？（目标 -30%）
□ 关键约束在前 3 节吗？
□ 没有 ═══？没有「不要 X」长串？没有自辩句？
□ 每节 ≤ 5 行？
□ 风格隔离声明存在？
```

## Gotchas

- **不要改提示词意图**：本 skill 只动格式和结构。意图层面的修改（如「克制」→「热烈」）是用户决策，不要自作主张。
- **不要无脑删风格词**：用户写了「胶片颗粒、印象派焦外、王家卫电影感」是有意为之，不要全删。删除冗余但保留意图明确的风格词。
- **节顺序可以微调**：标准 14 节顺序是默认，但场景特殊时（如纯文生图无参考图）可以省略「身份锚定 / 防混淆」等节。
- **风格隔离声明永远不能省**：只要有「风格关键词 + 人物」组合，就必须有风格隔离声明。否则风格会改写人脸。
- **多模型适配**：本 skill 主要针对 GPT Image 2 / Grok / Seedance 的最佳实践，不同模型 token 位置偏置可能略有差异，但「关键约束前置」是通用规律。
- **极简 ≠ 残缺**：压缩到 200 字以下时，确保 4 项核心约束都在（身份锚定 / 反偏差 / 风格隔离 / 防混淆）。再短就丢失关键功能了。

---

## 诚实边界

- 本 skill 优化的是「**格式效率**」，不是「**意图正确性**」
- 格式优化能让提示词从 750 字压到 400 字、关键约束权重提升，但**不能让本来表达错误的提示词变正确**
- 涉及内容/审美/合规问题时，先用 `image-prompt-master` 和 `ref-image-compliance-prompt-master`，再用本 skill 整理格式
