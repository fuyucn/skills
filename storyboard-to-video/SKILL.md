# 分镜到视频·AI制作全流程

> 好视频不只靠工具，靠的是清晰的故事线 + 风格锚点的统一贯穿。

---

## 核心工作流：五阶段流水线

```
文案脚本 → 分镜脚本 → 分镜图片 → 动态视频片段 → 剪辑合成
  DeepSeek    DeepSeek   Nano Banana    即梦/可灵        剪映
                         / 即梦         / Runway
```

---

## Phase 1：策划与分镜脚本

**分镜生成提示词模板**（向 DeepSeek 描述需求）：

```
给我一个专业的[时长]分镜提示词，要求：
[场景背景]
[主角描述]
[动作/表情]
```

**通用分镜脚本模板**：

```
你是一个专业的视频分镜师。请根据以下文案，生成一个详细的分镜脚本。
要求包括：镜号、画面描述、旁白文案、画面类型（图示/实景/动画）、
景别（全景/中景/特写）。
```

**关键输出格式**：

| 镜号 | 画面描述 | 旁白文案 | 画面类型 | 景别 | 时长 |
|------|---------|---------|---------|------|------|

## Phase 2：分镜图片生成

**关键原则**：
- **在此阶段确定统一风格关键词**，后续所有生成必须复用
- 控制色彩和构图，避免杂乱
- 固定核心人物/IP形象，确保角色一致性

---

## Phase 3：视频动画化

**运动提示词公式**：`[镜头运动] + [动作描述] + [时长] + [风格质感]`

| 中文 | 英文 | 效果 |
|------|------|------|
| 缓慢推进 | slow push in | 聚焦强调 |
| 缓慢拉远 | slow pull out | 突显全景 |
| 水平移动 | pan left/right | 展示全貌 |
| 固定机位 | static shot | 稳定展示 |
| 轻微抖动 | subtle handheld | 真实感 |

---

## Phase 4：实景演示录制（可选）

- 工具：腾讯会议（发起个人会议进行录制）
- 用途：产品功能演示，与动画片段混剪

---

## Phase 5：剪辑合成（剪映）

1. 导入所有素材 → 主轨道按分镜顺序拼接
2. 画中画轨道叠加演示视频
3. 配音 → 背景音乐 → 字幕
4. 统一调色 → 导出成品

---

## Seedance 2.0 工作流选择

| 路径 | 流程 | 审核宽严 | 适用场景 |
|------|------|---------|---------|
| **图生视频** | 先生成分镜图 → 再以图生成视频 | 较严格 | 精确控制画面构图 |
| **文生视频（参考图模式）** | 参考图 + 分镜提示词 → 直接生成视频 | 相对宽松 | 更大创作空间 |

**结论**：优先选择「参考图 + 分镜提示词」而非「分镜图生视频」。

---

## Gotchas

- **风格锚点必须在 Phase 2 确定并全程复用**：每个 Phase 独立生成时，如果不在提示词末尾加相同的风格关键词，最终视频各片段风格会不统一，剪辑时难以合并。
- **分镜图作为 Grok/Seedance 输入时人物会漂移**：使用真实人物参考图时，用「参考图+提示词」模式而非「分镜图生视频」，保留更好的人物一致性。
- **角色卡 vs 真人照片**：使用角色卡作为参考可规避平台真人肖像审核，且跨场景一致性更好。
- **长视频需多片段拼接**：多数工具单次生成 5-10 秒，超过此长度需要多段拼接，在剪映合成阶段处理。

## 逆向工程：分镜解构

用于分析优秀视频 → 还原其提示词：

```
请你扮演一位专业的电影分析师和顶尖的AI提示词工程师。
基于我上传的视频文件，对其进行分镜解构，并为每个关键分镜逆向推导出
能够生成该画面的AI视频提示词和场景文案。

分析必须严格遵循以下六个维度：
1. 电影化镜头设计：镜头类型、角度、运动、构图
2. 主角塑造与叙事性动作
3. 世界构建与材质细节
4. 风格锚点与光线物理
5. 沉浸式音景
6. 节奏与剪辑逻辑

输出格式：
【总体分析】整体风格、核心风格锚点、音景设计
【分镜提示词逆推】按"分镜N (时间段)"格式逐个输出
```
