# 分镜到视频·AI制作全流程

> 好视频不只靠工具，靠的是清晰的故事线 + 风格锚点的统一贯穿。

## 核心工作流：五阶段流水线

```
文案脚本 → 分镜脚本 → 分镜图片 → 动态视频片段 → 剪辑合成
  DeepSeek    DeepSeek   Nano Banana    即梦/可灵        剪映
                         / 即梦         / Runway
```

### Phase 1：策划与分镜脚本

**目标**：将文案转化为结构化分镜脚本

**分镜生成提示词模板（向 Codex / DeepSeek 描述需求）**：
```
给我一个专业的[时长]分镜提示词，要求：
[场景背景，如：真实的2030年世界杯直播，第60分钟，中国和巴西一比一战平]
[主角描述，如：镜头转到一名美丽的中国队女球迷]
[动作/表情，如：她自然地露出微笑，挥手并送出飞吻，并对着镜头比出爱心手势]
```

等待几秒即可得到完整的专业分镜提示词。

**通用分镜脚本模板（DeepSeek）**：
```
你是一个专业的视频分镜师。请根据以下文案，生成一个详细的分镜脚本。
要求包括：镜号、画面描述、旁白文案、建议的画面类型（如图示、实景、动画）、
建议的镜头景别（如全景、中景、特写）。
```

**关键输出格式**：
| 镜号 | 画面描述 | 旁白文案 | 画面类型 | 景别 | 时长 |
|------|---------|---------|---------|------|------|

### Phase 2：分镜图片生成

**工具选择**：
- Nano Banana：根据分镜脚本批量生成对应图片
- 即梦：中文场景补充，风格一致性强

**关键原则**：
- **在此阶段确定统一风格关键词**，后续所有生成必须复用
- 控制色彩和构图，避免杂乱
- 固定核心人物/IP形象，确保角色一致性

---

### Phase 3：视频动画化

**操作流程**：
1. 将静态图片导入即梦 / 可灵
2. 添加简单运动提示词（见下方模板）
3. 生成短视频片段（建议3-5秒/片段）

**运动提示词公式**：
```
[镜头运动] + [动作描述] + [时长] + [风格质感]
```

**常用镜头运动词**：
| 中文 | 英文 | 效果 |
|------|------|------|
| 缓慢推进 | slow push in | 聚焦强调 |
| 缓慢拉远 | slow pull out | 突显信息重压/全景 |
| 水平移动 | pan left/right | 展示全貌 |
| 固定机位 | static shot | 稳定展示 |
| 轻微抖动 | subtle handheld | 真实感 |

---

### Phase 4：实景演示录制（可选）

- 工具：腾讯会议（发起个人会议进行录制）
- 设置：高分辨率，关闭系统通知
- 用途：产品功能演示，与动画片段混剪

---

### Phase 5：剪辑合成

**剪映操作流程**：
1. 导入所有素材（动画视频 + 演示片段 + 音效）
2. 主轨道按分镜顺序拼接
3. 画中画轨道叠加演示视频
4. 添加配音 → 背景音乐 → 字幕
5. 统一调色 → 导出成品

**音视频协同原则**：
- 根据配音节奏调整视频片段时长
- 音效与画面动作精确同步
- 背景音乐情绪与画面内容匹配

## 六维分镜分析框架

用于**逆向工程**：分析优秀视频 → 还原其提示词

**核心提示词**：
```
请你扮演一位专业的电影分析师和顶尖的AI提示词工程师。
基于我上传的视频文件，对其进行分镜解构，并为每个关键分镜逆向推导出
能够生成该画面的AI视频提示词和场景文案。

分析必须严格遵循以下六个维度：

1. 电影化镜头设计：镜头类型、角度、运动、构图
2. 主角塑造与叙事性动作：识别画面"主角"，分析其行为的叙事意图
3. 世界构建与材质细节：环境背景、物体材质、纹理、时代风格
4. 风格锚点与光线物理：识别"风格锚点"，分析光线的具体物理表现
5. 沉浸式音景：环境音、音效及音乐使用策略
6. 节奏与剪辑逻辑：镜头切换时机与节奏感

输出格式：
【总体分析】整体风格、核心风格锚点、音景设计
【分镜提示词逆推】按"分镜N (时间段)"格式逐个输出
```

## 风格类型速查

### 企业产品视频（最常用）

**风格锚点**：企业级扁平化3D动态信息图

| 特征维度 | 描述 |
|---------|------|
| 视觉语言 | 2.5D/伪3D，元素有体积感但保留扁平特征 |
| 色彩 | 低饱和度马卡龙色系，干净清爽 |
| 材质 | 光滑哑光，浮动白色卡片/半透明玻璃 |
| 动效 | 路径动画、缩放、元素聚合 |

**通用风格提示词**：
```
极简扁平化3D风格，低饱和度马卡龙色系，光滑哑光材质，
柔和均匀环境光，细微柔和投影，企业产品介绍片调性
```

### 典型分镜提示词示例

**冲突/问题场景**：
```
极简扁平化3D风格。一个[职业]卡通职员，困惑挠头，站在中央。
被大量彩色几何化的[领域]图标和文件从四面八方包围。
背景为柔和的浅蓝色。镜头缓慢俯视拉远，突显信息重压。
柔和均匀环境光，细微柔和投影。
```

**解决方案/成功场景**：
```
商业扁平化卡通风格。一个[职业]卡通职员，从挠头困惑变为双手高举庆祝。
[视觉元素]从其指向右上方快速增长的图表卡片。
极简室内背景，温暖明亮光线，动态曲线表现效率提升和成功。
```

**界面演示场景**：
```
真实软件界面模拟动画。全景展示[产品名]的[界面类型]，
画面中[具体操作描述]。界面细节精致，光线均匀，Kanban/Grid布局。
```

## 场景锚定图：控制人物站位的核心方法

> 做 AI 视频最难的不是动作，而是如何在同一场景下精准控制人物的站位和走位。

### 核心问题

仅用文字提示词（哪怕是 GPT 生成的专业拍摄脚本），人物站位依旧会乱。**加入「场景锚定图/关键帧画面」后，立刻顺畅。**

多人武打/复杂场景：场景锚定图 + 武打分镜草图，成功率接近 **100%**。

### 生成输入组合

```
场景锚定图（1-2张）+ 人物角色卡 + 场景图 → Seedance 2.0 全能参考模式
```

### 如何获取场景锚定图

**方式 1**：基于场景图，生成该视角的人物图片
- 输入：场景环境图
- 用香薰模型（细节比较），自然语言描述角色在场景中的位置

**方式 2（更常用）**：截取前一段视频的关键帧
- 从已有视频中截取一帧作为场景锚定
- 保留了真实的镜头角度、光线、空间关系

### 专业拍摄脚本格式（江湖论模板）

两栏结构：**叙事轨迹（70%）** + **摄影机 & 人物站位（30%）**

每个分镜包含：
```
镜号 | 镜头类型名
时间范围 | 时长

叙事描述：
  - 场景氛围与人物状态
  - 对话台词（如有）

相机运动：
  - 景别、运动方式、光线处理

声音设计：
  - 环境音、音效、音乐

图例（人物站位）：
  - [角色A]（固定坐北侧）
  - [角色B]（起点/轨迹）

轨迹：→→ 运动方向标注
```

**示例（5镜头武侠场景）**：

| 镜号 | 类型 | 时长 | 核心内容 |
|------|------|------|---------|
| 01 | 全景·建立镜头 | 4s | 环境建立，人物从远处入画 |
| 02 | 中景·人物入画 | 3s | 走到指定位置，二人对视 |
| 03 | 面部特写 | 2s | 情绪特写，台词 |
| 04 | 手部特写·动作 | 2s | 关键动作细节 |
| 05 | 中景·二人同框 | 4s | 场景收束，情绪推进 |

## 实战案例：3x3分镜图 → 10秒连续视频（Grok）

**场景**：用户提供一张 3x3 的参考分镜图（9个画面），要求 Grok 生成一段 10 秒自然连续的视频。

**核心挑战**：避免生成「9张静图拼接」的效果，需要真实的镜头运动和人物连贯动作。

### 有效提示词结构

```
请根据参考图中的3x3分镜，使用Grok帮我生成一段[时长]完整连续视频。

视频主题：
[场景描述，包含时间/地点/事件/比分/氛围等具体细节]
整体保持参考图的人物外貌、服装、发型、[特征细节]、
[环境元素]、镜头色彩、[品牌/风格标识]和现场氛围。

核心要求：
生成一段连续自然的[时长]视频，不是[N]张静态图拼接。
镜头之间需要有[转播风格]的自然切换、[镜头运动类型]和现场摄像机运动。
人物动作要连贯自然，表情真实，不僵硬。

画面风格：
[风格锚定词，如：超真实体育直播风格、像真实XXX电视转播中的特写镜头]
```

### 关键参数说明

| 要素 | 作用 | 示例 |
|------|------|------|
| **参考图风格锚定** | 保持人物/环境/色彩一致 | 「整体保持参考图的人物外貌、服装、发型」 |
| **反向约束** | 明确告知不要的效果 | 「不是9张静态图拼接」 |
| **镜头运动类型** | 赋予真实感 | 「轻微推拉、跟焦、景深变化、现场摄像机运动」 |
| **转播风格锚定** | 定义整体质感 | 「真实世界杯电视转播风格」 |
| **动作连贯描述** | 防止僵硬感 | 「人物动作连贯自然，表情真实，不僵硬」 |

### 镜头运动补充词（体育/真实感场景）

## Seedance 2.0 工作流选择

### 文生视频 vs 图生视频的模式差异

Seedance 2.0 的两种生成路径，内容审核宽严不同：

| 路径 | 流程 | 审核宽严 | 适用场景 |
|------|------|---------|---------|
| **图生视频** | 先生成分镜图 → 再以图生成视频 | 较严格 | 精确控制画面构图 |
| **文生视频（参考图模式）** | 参考图 + 分镜提示词 → 直接生成视频 | 相对宽松 | 更大创作空间 |

**结论**：想要更灵活的内容表达，优先选择「参考图 + 分镜提示词」而非「分镜图生视频」。

### 角色卡 vs 真人照片

使用**角色卡**（风格化角色设计图）作为参考图，比直接上传真人照片有以下优势：

- 规避平台对真人肖像的额外审核
- 避免产生真人 deepfake 的伦理与法律风险
- 角色一致性更容易跨场景保持

**角色卡制作方式（GPT Image 2 实测流程）**：

Step 1 — 上传角色原图，使用以下提示词：
```
把我生成这张照片女主角的角色卡片：包含正面侧面背面三视图，
以及多表情面部特写，和手部不同动作的特写，
保持女主角的外貌发型身材服饰气质完全不变
```

Step 2 — 得到包含以下内容的角色卡：
- 三视图（正面 / 侧面 / 背面）
- 多表情面部特写
- 手部不同动作特写

Step 3 — 以该角色卡作为后续所有分镜生成的参考图输入

## 诚实边界

- 本方法论基于 2025 年工具生态，各工具功能持续更新
- 角色一致性仍是 AI 视频的核心难题，复杂场景需要多次迭代
- Runway 等英文工具在中文提示词上表现不稳定
- 生成视频的时长目前普遍受限（多数工具 5-10 秒/片段），长视频需要多片段拼接
