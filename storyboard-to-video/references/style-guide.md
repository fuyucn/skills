# 视频风格指南

> 读取条件：需要企业视频风格参考或完整分镜示例时。

## 企业产品视频（最常用）

**风格锚点**：企业级扁平化3D动态信息图

| 特征维度 | 描述 |
|---------|------|
| 视觉语言 | 2.5D/伪3D，元素有体积感但保留扁平特征 |
| 色彩 | 低饱和度马卡龙色系，干净清爽 |
| 材质 | 光滑哑光，浮动白色卡片/半透明玻璃 |
| 动效 | 路径动画、缩放、元素聚合 |

**通用风格提示词**：
```
极简扁平化3D风格，低饱和度马卡龙色系，光滑哑光材质，
柔和均匀环境光，细微柔和投影，企业产品介绍片调性
```

## 典型分镜提示词示例

**冲突/问题场景**：
```
极简扁平化3D风格。一个[职业]卡通职员，困惑挠头，站在中央。
被大量彩色几何化的[领域]图标和文件从四面八方包围。
背景为柔和的浅蓝色。镜头缓慢俯视拉远，突显信息重压。
柔和均匀环境光，细微柔和投影。
```

**解决方案/成功场景**：
```
商业扁平化卡通风格。一个[职业]卡通职员，从挠头困惑变为双手高举庆祝。
[视觉元素]从其指向右上方快速增长的图表卡片。
极简室内背景，温暖明亮光线，动态曲线表现效率提升和成功。
```

**界面演示场景**：
```
真实软件界面模拟动画。全景展示[产品名]的[界面类型]，
画面中[具体操作描述]。界面细节精致，光线均匀，Kanban/Grid布局。
```

## 视频结构模板（产品宣传片）

```
(0:00-0:25) 开场设问     → 直击目标用户痛点
(0:26-0:45) 解决方案登场  → 产品优雅引入
(0:46-1:25) 核心功能展示  → 3-4个支柱功能（每个15-20s）
(1:26-1:40) 价值升华     → 抽象利益/情感共鸣
(1:41-1:55) 信任背书     → 客户案例/数据
(1:56-2:00) 号召行动     → CTA
```

## 3x3分镜图 → 连续视频（Grok）

**有效提示词结构**：

```
请根据参考图中的3x3分镜，使用Grok帮我生成一段[时长]完整连续视频。

视频主题：
[场景描述，包含时间/地点/事件/比分/氛围等具体细节]
整体保持参考图的人物外貌、服装、发型、[特征细节]、
[环境元素]、镜头色彩和现场氛围。

核心要求：
生成一段连续自然的[时长]视频，不是[N]张静态图拼接。
镜头之间需要有[转播风格]的自然切换、[镜头运动类型]和现场摄像机运动。
人物动作要连贯自然，表情真实，不僵硬。

画面风格：
[风格锚定词，如：超真实体育直播风格、像真实XXX电视转播中的特写镜头]
```

**镜头运动补充词（体育/真实感场景）**：
```
轻微推拉（subtle push/pull）、跟焦（rack focus）、
景深变化（depth of field shift）、现场手持摄像机运动（on-site handheld）
```
