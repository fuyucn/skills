# 工具选型矩阵

> 读取条件：需要选择视频制作工具时。

| 工具 | 核心优势 | 适用阶段 | 中文支持 |
|------|---------|---------|---------|
| **DeepSeek** | 智能生成结构化分镜脚本 | Phase 1 | ✅ 优秀 |
| **Nano Banana** | 根据分镜批量生成图片 | Phase 2 | ✅ 良好 |
| **即梦 (Dreamina)** | 首尾帧生成视频，中文优秀 | Phase 2+3 | ✅ 最佳 |
| **可灵 (Kling)** | 角色记忆，30秒动漫视频 | Phase 3 | ✅ 良好 |
| **Runway Gen-3** | 专业级视频质量 | Phase 3（成片阶段） | ❌ 英文为主 |
| **剪映** | 剪辑/字幕/调色一体 | Phase 5 | ✅ 最佳 |
| **腾讯会议** | 高质量屏幕录制 | Phase 4 | ✅ 优秀 |

**选型原则**：
- 全中文工作流 → 即梦 + 可灵 + 剪映
- 追求最高画质 → Runway（需要英文提示词能力）
- 角色一致性强 → 可灵 3.0（支持角色记忆）
