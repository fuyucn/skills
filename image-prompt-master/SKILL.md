# 图片提示词大师

> 写不了「性感」，但可以写出比「性感」更高级的东西。

---

## 核心框架：审美词 vs 欲望词

系统识别的是**词语的语义倾向**，而非创作意图。解决方案是**用专业审美语言精准描述视觉效果**。

| 你想表达的 | ❌ 欲望词 | ✅ 审美词 |
|-----------|---------|---------|
| 吸引力强 | 性感、诱惑、挑逗 | 高级女性魅力、优雅气质、成熟自信 |
| 身材好 | 胸大、翘臀、火辣 | 身材比例完美、曲线优美、体态优雅 |
| 衣着少 | 裸露、暴露、湿身 | 高级时装、精致服装、时尚穿搭 |
| 姿势撩人 | 挑逗、低机位、擦人 | 自然优雅的姿态、高级时尚大片感 |
| 皮肤好 | — | 丝滑肌肤质感、柔和光影、白皙通透 |
| 眼神魅力 | 勾魂、魅惑 | 深邃眼神、自信从容、眼神有故事感 |

## GPT Image 2 模式选择

| 模式 | 被审查概率 | 说明 |
|------|---------|------|
| **Instant 模式**（默认） | 较高 | 快速生成，安全过滤激进 |
| **Thinking 模式** | 明显降低 | 模型先推理再生成，审查更宽松 |

**首先切换到 Thinking 模式，再配合审美词，通过率显著提升。**

## 5 种问题精准修复

### 情况 1：生成失败 / 被 ban

**前置**：确认已开启 Thinking 模式。

**剔除**：
```
性感 / 挑逗 / 魅惑 / 胸 / 低机位 / 湿身 / 裸露 / 诱惑 / 暴露
色情 / erotic / horny / seductive pose / lustful expression
```

**替换为**：
```
成熟 / 优雅 / 健康 / 自信 / 自然曲线 / 高级女性美 / 商业人像 / 得体服装
```

### 情况 2：结果太保守，不够好看

补充：
```
增强人物的时尚时装表现力 / 高级女性气质 / 优化身体比例与姿态
让体态更圆润匀称 / 增强服装剪裁的贴合度 / 柔和光影和皮肤质感
```

### 情况 3：身材变形（手指/四肢异常）

末尾追加：
```
身体比例自然协调，肩宽、腰线、腿部长度符合真实人体结构，
手指数量正确，四肢自然，坐姿稳定，避免全身扭曲和肢体畸形。
```

### 情况 4：脸太幼

补充：
```
脸型为成熟自然的成年女性脸型，不幼态，不儿童化，五官精致但成熟，气质温柔自信。
```

### 情况 5：画面太擦边

加入：
```
整图回到高级商业人像和角色设计表达，减少身体暴露，强调服装、光影、动态和人物气质。
```

## 提示词结构

```
[人物：外貌/气质/年龄感（25岁以上成年）]
+ [服装/材质：具体服饰，含遮挡层设计]
+ [场景/背景：环境氛围，简洁克制]
+ [光影：方向、质感、与身体的关系]
+ [姿态：服务于主视觉的动作]
+ [构图：比例/景别/视角]
+ [风格锚定：商业/艺术/编辑向]
+ [比例修正]（情况3必加）
+ [成熟度描述]（情况4必加）
+ [负向约束列表]
```

## 通用构图技法

| 技法 | 原理 | 应用示例 |
|------|------|---------|
| **主视觉转移** | 把重心移离正面/敏感区域 | 背部主视觉、侧面构图 |
| **遮挡层设计** | 服装/布料/阴影叠加遮挡 | 薄纱+肤色内层 |
| **光线替代描述** | 用光线效果代替身体描述 | 逆光勾轮廓、焦散光斑 |
| **风格锚定** | 明确定性为商业/艺术向 | 时尚杂志街拍、编辑写真 |
| **负向约束** | 主动排除触发词 | 不要低俗姿势/不要情色化表达 |

## Gotchas

- **Instant 模式拒绝率远高于 Thinking 模式**：即使提示词无问题，Instant 模式也可能误拒。遇到拒绝先切换模式，不要急着改提示词。
- **负向约束反而触发审查**：写「不要色情」「不要裸露」反而可能触发关键词检测。改为正向描述：「高级商业人像」「优雅时装大片」。
- **连续多次被拒后该账号触发更严格过滤**：短时间内多次提交相似被拒提示词，会导致账号级别的临时限制。换个方向重写，不要重复提交相似内容。
